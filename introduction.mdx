ExamMaster is a full-stack online exam portal built on the MERN stack (MongoDB, Express.js, React, Node.js). It provides role-based access control that lets Admins and Teachers create and manage exams, while Students can attempt assigned exams and track their progress.

## What ExamMaster Does

The platform supports both objective (multiple-choice) and subjective (free-text) exams. Admins organize exams by subject and type, assign them to specific students, and set model answers for automatic or assisted grading. Students see only the exams assigned to them, submit answers within the exam flow, and receive instant results for objective questions. Subjective answers are scored by a Python-based evaluator that compares student responses against model answers using semantic similarity, keyword coverage, and grammar analysis.

## User Roles

<CardGroup cols={2}>
  <Card title="Admin / Teacher" icon="user-shield">
    Create objective and subjective exams, organize by subject and type, assign exams to students, and review results.
  </Card>

  <Card title="Student" icon="graduation-cap">
    Attempt assigned exams, view instant objective scores, and track complete exam history.
  </Card>
</CardGroup>

Role assignment happens automatically at signup based on the email domain: addresses ending in `@exam-portal.com` become Admin/Teacher, while all other domains become Student.

## Feature Summary

| Capability | Admin / Teacher | Student |
| --- | --- | --- |
| Create objective exams | Yes | No |
| Create subjective exams | Yes | No |
| Organize exams by subject and type | Yes | No |
| Assign exams to students | Yes | No |
| Attempt assigned exams | No | Yes |
| View instant objective scores | No | Yes |
| Track exam history | No | Yes |
